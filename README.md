# RA2 Rules.INI 编辑器 使用说明

## 一、软件简介

**RA2 Rules.INI 编辑器** 是一款面向《红色警戒2：尤里的复仇》Mod 玩家与开发者的图形化 INI 配置编辑器。它支持读取、查看、编辑、保存 RA2 的各类 INI、地图、PKT 配置文件，并内置中文说明、智能识别、批量编辑、项目合并等高级功能，让 Mod 修改工作大幅简化。

**主要特点**：

- 无损编辑：保留原文件注释、空行、编码、换行符，不破坏原文件结构。
- 智能识别：自动判断打开的文件是 rules、art、ai、map 还是 pkt 等类型。
- 中文说明：加载 explanation/ 下的说明文件，为每个键提供中文解释。
- 注册列表：图形化浏览 `[InfantryTypes]`、`[VehicleTypes]` 等注册表，双击即可跳转。
- 项目模式（实验性）：把多个 INI 合并为一个项目，支持 `[#include]` 语法。
- 单位属性编辑器：批量编辑步兵、载具、飞行器、建筑的关键属性。
- 国家与所属色编辑器：图形化编辑 `[Sides]`、`[Colors]`、`[Countries]`。
- 自动保存：定时把当前编辑内容存为副本，防止崩溃丢失。
- 无依赖：打包后即可运行，无需安装 Python。

> **警告**：项目模式为实验性功能，使用前请务必备份所有 INI 相关文件。

## 四、快速上手

### 1. 打开文件

点击 **文件 → 打开...**（或工具栏"打开INI文件"），选择一个 INI / MAP / MPR / YRM / PKT 文件。

程序会自动识别文件类型（rules、art、ai、map、pkt 等），显示在窗口右上角。

### 2. 浏览节与键

- 左侧"节（Section）列表"显示所有 `[Section]`。
- 点击某个节，右侧"键值对信息"表格显示该节所有 `Key=Value`。
- 下方"说明"区显示当前选中键的中文解释。

### 3. 编辑键值对

- **双击**右侧任意一行，弹出修改对话框。
- 也可以右键 → 修改选中项 / 删除选中项。
- 支持多选删除。

### 4. 保存

点击 **文件 → 保存**（Ctrl+S）写回原文件；**文件 → 另存为** 可保存到其他位置。

程序只修改变化的行，原文件的注释、空行和格式不会被破坏。

## 六、核心功能详解

### 1. 智能识别文件类型

编辑器根据文件的**扩展名**、**独有节名**、**独有键名**自动判断文件类型：

| 类型 | 特征 |
|---|---|
| rules | 含 `[General]`、`[InfantryTypes]` 等 |
| art | 含 `[Movies]`、`Cameo=` 等 |
| ai | 含 `[TaskForces]`、`[TeamTypes]` 等 |
| map | 扩展名 `.map/.mpr/.yrm`，含 `[IsoMapPack5]` |
| pkt | 扩展名 `.pkt`，含 `[MultiMaps]` |
| theme | 含 `[Themes]` |
| eva | 含 `[DialogList]` |
| theater | 含 `[TileSet0000]` |

识别结果会显示在窗口右上角，并根据类型优先加载对应的说明文件。

### 2. 注册列表联动

左侧"注册列表"下拉框会自动列出文件中存在的注册表，例如：

- `InfantryTypes`（步兵注册列表）
- `VehicleTypes`（载具注册列表）
- `BuildingTypes`（建筑注册列表）
- `Warheads`（弹头注册列表）
- ...

选中某个注册表后，列表显示所有注册项；**双击**某项即可跳转到对应的节。

### 3. 说明文件

程序启动时会自动从以下位置查找说明文件：

1. `exe 同目录/explanation/`
2. 脚本所在目录的 `explanation/`
3. 项目根目录的 `explanation/`
4. 当前工作目录的 `explanation/`

**查找优先级**：

- art 文件：arts_explanation.txt 优先
- rules 文件：rules_explanation.txt 优先，arts_explanation.txt 其次
- 武器/弹头/抛射体：weapons_explanation.txt（按节类型分三段）
- 全局设置：general_explanation.txt
- AI 相关：ai_explanation.txt
- Ares 扩展：ares_explanation.txt（最低优先级）

### 4. 自动保存

程序每 3 分钟自动把当前编辑内容保存到 `saves/` 目录，最多保留 5 个副本。

点击 **文件 → 打开保存副本文件夹** 可查看。

> **注意**：项目模式下自动保存会被关闭，请及时手动保存项目。

## 七、项目模式（实验性）

### 项目是什么

一个"项目"是一个 `.iniproject` 文件，它记录了：

- 项目名
- 项目包含的所有文件
- 每个文件通过 `[#include]` 引用的子文件
- 项目所需的帮助文件（txt）
- 最后编辑时间

### 支持的 INI 文件

项目会自动识别目录下的以下文件（`x` 可以是任意后缀，如 `md`、`mo`、`ra2` 等）：

- `rulesx.ini`
- `artx.ini`
- `aix.ini`
- `missionx.ini`
- `battlex.ini`
- `mapselx.ini`
- `evax.ini`
- `soundx.ini`
- `themex.ini`
- `uix.ini`
- `mpmodesx.ini`
- `missionx.pkt`

例如：如果用户输入的 rules 文件名是 `rulesmo.ini`，则程序只匹配 `artmo.ini`、`aimo.ini` 等，**不会误匹配** `artmd.ini`。

### 合并规则

- 项目把所有文件的节合并到一张总表中。
- 同名节的所有键值对会合并显示。
- **键重复时，按优先级只保留最高优先的键**。
- 优先级顺序：`rulesx.ini` > `artx.ini` > `aix.ini` > ...

### `[#include]` 支持

如果某个 INI 文件包含 `[#include]` 节，例如：

```ini
[#include]
1=rules_sw.ini
2=rules_vehicles.ini
3=rules_infantry.ini
```

则项目会自动加载这些子文件，并**让子文件的键优先于主文件**。例如 `rules_infantry.ini` 中的 `[E1]` 会覆盖 `rulesmd.ini` 中的 `[E1]`。

### 项目模式的限制

- **禁止添加节**（右键菜单已禁用）
- **禁止删除节**
- **禁止重命名节**
- **禁止复制/粘贴节**
- **禁止添加键**（编辑菜单和右键菜单已禁用）
- **允许修改现有键的值**
- **允许删除键**
- **允许通过单位/国家编辑器添加键**

### 项目属性

菜单 **项目 → 项目属性...** 显示：

- 项目名、项目文件、项目目录、最后编辑时间
- 已有文件列表（含 `[#include]` 标记）
- 缺失文件列表
- 帮助文件列表
- 合并后的节数量

## 九、国家与所属色编辑器

菜单 **项目 → 国家与所属色编辑器...** 打开。

### 界面布局

- 左侧：阵营列表（来自 `[Sides]` 的键）
- 中间：该阵营的国家列表（来自 `[Sides]` 的值，按逗号拆分）
- 右侧：国家属性编辑

### 可编辑属性

| 中文名 | 键名 | 输入方式 |
|---|---|---|
| 国名 | Name | 文本 |
| 显示国名 | UIName | 文本 |
| 是否可选 | Multiplay | yes/no |
| 阵营 | Side | 下拉（所有阵营名） |
| 所属色 | Color | 下拉（所有颜色名，带色块） |
| 智慧AI | SmartAI | yes/no |

### 一致性检查

如果某国家的 `Side=` 值与它在 `[Sides]` 中所在的阵营不符，顶部会显示红色警告，但允许保存。

### 查看所属色表

点击 **查看所属色表**，弹出窗口列出 `[Colors]` 中所有颜色名、HSL 值和对应色块。

RA2 的 `[Colors]` 值格式是 **`H,S,V`**（H 0-255，S 0-255，V 0-255），不是 RGB。编辑器会自动转换为 RGB 以显示色块。

## 十、常见问题

### Q1：说明文件没有加载怎么办？

点击 **帮助 → 查看说明文件加载状态...**，检查每个文件的 `[OK]` 或 `[缺失]` 状态。

如果显示 `[缺失]`：

1. 确认 `explanation/` 文件夹与 exe 在同一个目录。
2. 确认文件名拼写正确（如 `rules_explanation.txt`）。
3. 如果仍有问题，用 `--console` 版 exe 启动，看控制台输出。

### Q2：为什么修改了键但文件没变？

- 修改后必须点击 **文件 → 保存** 才会写回。
- 项目模式下，必须点击 **项目 → 保存项目**。
- 自动保存只生成副本，不覆盖原文件。

### Q3：可以修改键名吗？

- 普通模式：可以，双击修改。
- 项目模式：**禁止修改键名**，只允许改值。

### Q4：为什么有些键没有中文说明？

说明文件只覆盖常见键。如果是 Mod 自定义键，可在 `explanation/` 中手动添加。

### Q5：项目模式下为什么不显示某个节？

- 确认该节所在的文件已加入项目。
- 如果文件通过 `[#include]` 引用，确认子文件与主文件在同一目录。
- 在 **项目 → 项目属性** 中查看缺失文件。

### Q6：地图文件打开后键很少？

地图文件用 `IsoMapPack5` 等节存储地形数据，是 Base64 编码的二进制块，并非 INI 文本键值对，这是正常现象。

### Q7：如何恢复误删的键？

点击 **文件 → 打开保存副本文件夹**，从 `saves/` 中找回自动保存的副本。

1. **实验性功能**：项目模式、单位编辑器、国家编辑器为实验性功能，使用前**请务必备份所有 INI 文件**。

5. **兼容性**：编辑器针对《红色警戒2：尤里的复仇》原版 INI 编写，Ares、Phobos 等扩展的键说明可能不全。
